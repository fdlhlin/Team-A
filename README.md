# StatVision

Interactive Statistical Analysis Platform built using R Shiny.

## Features
- Data Input (CSV upload)
- Descriptive Statistics
- Data Visualization
- Hypothesis Testing
- Correlation & Regression Analysis
- User Guide

## Requirements
R packages:
- shiny
- bslib
- bsicons
- DT
- ggplot2

## How to Run
1. Open RStudio
2. Install required packages
3. Run app.R
